# ss

精简版 V2Ray 脚本（仅保留 Shadowsocks + BBR）。

## 一键安装
```bash
bash <(curl -sL https://raw.githubusercontent.com/osirzzzz/ss/main/install.sh)
```

## 主要特性
- 仅保留 Shadowsocks
- 保留 BBR
- 默认加密：`aes-128-gcm`
- 安装完成自动创建 Shadowsocks
- 自动显示链接和二维码

## 常用命令
```bash
v2ray
v2ray ss
v2ray ssqr
v2ray bbr
v2ray status
v2ray restart
v2ray log
v2ray uninstall
```
